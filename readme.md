# Discover
## 📖 Sobre o projeto

**Discover** é um projeto de página pessoal inspirado em um curso da [Rocketseat](https://www.rocketseat.com.br/). A proposta é criar uma página web para centralizar links importantes em um único lugar, com uma interface simples e personalizável.

O projeto também explora conceitos fundamentais do desenvolvimento front-end, utilizando HTML para estruturar a página, CSS para definir sua aparência e JavaScript para adicionar interatividade.

## ✨ Funcionalidades

- **Página de links:** centralização de links pessoais em uma única interface.
- **Tema claro e escuro:** alternância visual por meio de um botão interativo.
- **Perfil personalizado:** exibição de avatar e identificação do perfil.
- **Links para redes sociais:** acesso rápido a perfis externos.
- **Interface responsiva:** estrutura preparada para diferentes tamanhos de tela.
- **Estilização personalizada:** uso de CSS para controlar cores, imagens de fundo e elementos da interface.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Finalidade |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Layout, cores, temas e responsividade |
| JavaScript | Interatividade e alternância de temas |
| Ionicons | Ícones da interface |
| Google Fonts | Tipografia |
| Git e GitHub | Versionamento e hospedagem do código |

## 📂 Estrutura do projeto

```text
Discover/
├── assets/
│   └── imagens e recursos visuais
├── index.html
├── style.css
├── scripts.js
└── README.md
```

- `index.html`: estrutura principal da página.
- `style.css`: estilos, layout e configuração dos temas.
- `scripts.js`: comportamento interativo da interface.
- `assets/`: recursos visuais utilizados pelo projeto.

## 🚀 Como executar

Não é necessário instalar dependências para visualizar a versão estática do projeto.

### 1. Clone o repositório

```bash
git clone https://github.com/aldobarduconeto/Discover.git
```

### 2. Acesse a pasta

```bash
cd Discover
```

### 3. Abra o projeto

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code para executar a página em um servidor local.

## 🎨 Personalização

Você pode adaptar o projeto às suas necessidades:

1. **Perfil:** altere o avatar e o nome exibidos no arquivo `index.html`.
2. **Links:** substitua os endereços existentes pelos seus próprios links.
3. **Aparência:** modifique as cores, imagens de fundo e estilos no arquivo `style.css`.
4. **Interatividade:** ajuste o comportamento de alternância de temas no arquivo `scripts.js`.
5. **Redes sociais:** atualize os endereços dos seus perfis na seção de rodapé.
